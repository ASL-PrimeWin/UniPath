# UniPath final build

This build keeps the team's 906-institution / 2,661-programme free-tier dataset in `data.js`.

## Major updates
- Homepage rebuilt to follow the provided visual references while keeping UniPath branding.
- Free / UniPath Pro switch on the homepage.
- Search now searches across all institution records and programme text.
- College filters include category, programme, entrance route, study mode, hostel and fee text.
- Find My College uses an 8-step matching flow and ranks the full dataset.
- NIRF page has separate category cards and verified 2025 rank examples.
- Login / Sign Up now opens the dedicated `register.html` demo account page.
- Compare and College Details were refreshed.

## Data rule
The uploaded team CSV is the source of truth for college/programme information. NIRF rank values are only shown where explicitly verified from NIRF India Rankings 2025 pages.

## GitHub Pages
Upload the extracted site files to the `main` branch. Keep an existing `.github` folder/workflow in the repository if you use one.
